# iBUSIM
Web app connecting Binghamton University's BUSIM flight simulator cockpit hardware to DCS World.

<img width="1115" height="526" alt="Screenshot 2026-08-27 115432" src="https://github.com/user-attachments/assets/58eeb0c2-1a6a-436e-8411-f69be9f4d088" />

## Requirements

- .NET 10 SDK
- Node.js and npm

## Run the backend

- cd backend/iBUSIM.Runtime
- dotnet run

## Run the frontend

- cd frontend
- npm install
- npm run dev
